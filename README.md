# Mexico Real Estate Price Analysis

An exploratory data analysis of Mexican residential property listings, investigating
whether prices are driven more by **property size** or by **location**.

## Research Question

Are property prices in Mexico more influenced by property size (`area_m2`) or by
location (`state`)?

## Summary of Findings

- Prices are **right-skewed**: a small number of high-value listings pull the mean
  well above the median.
- Size and price are **positively correlated nationally** (r ≈ 0.46), but this
  average conceals wide state-level variation — from weak to very strong
  relationships depending on the state (an example of **Simpson's Paradox**).
- After controlling for size with `price_per_m2`, a **variance decomposition**
  shows that **within-state variation is larger than between-state variation**.
  State-level median differences are real (Distrito Federal is systematically
  pricier than Colima, for example), but most of the spread in price-per-m²
  happens *within* a given state — pointing to unmeasured, property-level factors
  (condition, exact neighborhood, floor, amenities) that this dataset doesn't
  capture.
- **Neither size nor location fully explains price on its own.** Size matters —
  the national and several state-level correlations are moderate-to-strong — but
  it isn't the dominant factor once price is measured per square meter.

## Data

The three raw CSVs (`mexico-real-estate-1/2/3.csv`) are the starting point for
notebook 01. Each covers a different set of Mexican property listings, with a
different set of quirks handled during cleaning (currency conversion, a packed
`lat-lon` string column, missing coordinates). See notebook 01 for the full
cleaning rationale.

## Methods Used

- pandas method chaining, tidy-data cleaning
- Matplotlib and Seaborn for visualization
- Quantile-based outlier filtering
- Pearson correlation, correlation matrices, and per-group (segmented) correlation
- Feature engineering 
- Variance decomposition (between-group vs. within-group, a simplified ANOVA)

## Limitations

- The dataset has no neighborhood-, condition-, or amenity-level features, so
  "within-state variance" is really a stand-in for everything this dataset
  doesn't capture.
- Some state/property-type subgroups have small sample sizes; results for those
  groups are noted as less reliable rather than excluded outright where relevant.
- The exchange rate used for peso-denominated listings is a fixed approximation,
  not a per-transaction historical rate.

## 🧠 Critical Analysis & Methodological Corrections
While completing this project, I identified and corrected several methodological inconsistencies in the original coursework to ensure statistical validity:
1. **Outlier Handling Consistency:** The course introduced quantile-based outlier removal but subsequently reverted to the raw, uncleaned dataset for downstream analysis. I enforced a strict pipeline to ensure all grouped analyses and variance decompositions were performed on the *cleaned* dataset to prevent skewed results.
2. **Variance Decomposition Metric:** The original curriculum calculated between-state and within-state variance using raw `price_usd`. Because raw price is heavily confounded by property size, this yields misleading conclusions about the "location effect." I corrected the variance decomposition to use the engineered `price_per_m2` feature, which properly isolates geographic value density from physical size.
